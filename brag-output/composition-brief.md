# Hyperframes Composition Brief: Receyta

## Objective
Vídeo curto de divulgação do app Receyta (receitas, semana, modo cozinha, compras).

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: vertical — 1080x1920
- Duration: 24.6s

## Source Material
- Project root: o app Flutter (sem site; interface recriada em HTML a partir dos tokens e telas do app)
- Primary files read: tokens de cor, tipografia, telas de receitas, modo cozinha, compras, onboarding
- Product name: Receyta
- Tagline / strongest claim: "Suas receitas, num lugar só"
- Key UI or visual moment to recreate: cartão de receita com azulejo, modo cozinha com porções, notificação do timer, lista de compras
- Copy that must appear verbatim:
  - "Nenhuma receita ainda."
  - "Comece pelo nome — o resto entra depois."
  - "Suas receitas, num lugar só"
  - "Compras sem conta de cabeça"
  - "A lista sai das receitas, com as quantidades já somadas."
  - "Seus dados ficam só neste aparelho."

## Creative Direction
- Tone preset: app-store
- Creative direction: caderno de receitas que virou app, caloroso e limpo
- Angle: partir do estado vazio real do app e mostrar o caminho até a lista de compras
- Hook: "Nenhuma receita ainda."
- Outro / punchline: "Seus dados ficam só neste aparelho."
- Avoid: linguagem genérica de SaaS, fundos abstratos, redesenho da identidade
